## Context

- 오늘 날짜: !`date "+%Y-%m-%d (%A)"`
- 이번 주 월요일 날짜: !`date -v-monday "+%Y-%m-%d" 2>/dev/null || date -d "last monday" "+%Y-%m-%d" 2>/dev/null || date "+%Y-%m-%d"`
- 이번 주 커밋 목록 (이번 주 월요일 ~ 오늘): !`git log --oneline --after="last monday" --format="%h %ad %s" --date=format:"%Y-%m-%d"`
- 이번 주 커밋 상세 (변경 파일 포함): !`git log --after="last monday" --stat --format="커밋: %h%n날짜: %ad%n메시지: %s%n" --date=format:"%Y-%m-%d"`

## 작업

위 커밋 정보를 바탕으로 **이번 주 주간 업무 보고서**를 작성해주세요.

보고서 형식:
```
=====================================
       주간 업무 보고서
  기간: [월요일 날짜] ~ [오늘 날짜]
=====================================

## 1. 주요 작업 요약
[커밋들을 카테고리별로 묶어서 핵심 작업 내용 요약]

## 2. 세부 작업 내역
[날짜순으로 각 작업 상세 내용]

## 3. 이번 주 성과
[완료된 기능, 수정된 버그, 개선사항 등]

## 4. 특이사항 / 메모
[특별히 언급할 내용이 있다면]

=====================================
총 커밋 수: [N]건
=====================================
```

커밋이 없는 경우에는 "이번 주 커밋 내역이 없습니다."라고 출력해주세요.
한국어로 작성하고, 기술적인 내용은 비개발자도 이해할 수 있도록 풀어서 설명해주세요.
